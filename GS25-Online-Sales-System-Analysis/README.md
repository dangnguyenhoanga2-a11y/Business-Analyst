# GS25 Online Sales System Analysis

## Project Overview

This project focuses on analyzing and designing an online sales management system for GS25 convenience store chain.

The system supports core business processes including:

- Product management
- Order processing
- Customer management
- Inventory management
- Payment processing
- Reporting and analytics

## My Responsibilities

- Analyzed business requirements
- Designed Use Case diagrams
- Modeled business processes using Activity and Sequence diagrams
- Designed system architecture and database structure
- Developed system workflows and user interface design
