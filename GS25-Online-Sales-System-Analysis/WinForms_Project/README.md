# GS25 Sales Management System – WinForms Application

## Project Overview

This project is a desktop application developed using Windows Forms (WinForms) to support the sales management operations of GS25 convenience store.

The system allows users to manage products, customers, orders, and inventory through a graphical user interface connected to a SQL Server database. The application is designed to improve operational efficiency, reduce manual errors, and support daily business activities.

## Objective

* Develop a desktop application for sales management
* Provide an intuitive user interface for store operations
* Integrate application with a SQL Server database
* Support data entry, updates, and reporting
* Improve data accuracy and workflow efficiency

## System Features

The application includes the following core features:

* User login and authentication
* Product management
* Customer management
* Order and sales management
* Inventory tracking
* Payment processing
* Basic reporting and data management

## System Architecture

The system follows a client-database architecture:

* Frontend: Windows Forms (WinForms)
* Backend: SQL Server database
* Programming Language: C#
* Database Access: ADO.NET

The application interacts with the database to perform CRUD operations (Create, Read, Update, Delete).

## Technologies Used

* C#
* Windows Forms (WinForms)
* Microsoft SQL Server
* ADO.NET
* Visual Studio

## Project Structure

This folder contains the source code of the WinForms application, including:

* Form files (.cs)

## How to Run the Application

1. Open the project in Visual Studio.
2. Restore the database using the provided SQL script.
3. Update the database connection string if needed.
4. Build and run the application.
