# Database Management System for FAHASA Sales Management

## Project Overview

This project focuses on designing and implementing a database management system for the sales operations of FAHASA bookstore. The system supports both online and offline sales activities, ensuring accurate data storage, efficient transaction processing, and reliable inventory management.

The database is designed to automate business processes, maintain data integrity, and support reporting and decision-making for sales management.

## Objective

* Design a structured database for managing sales operations
* Ensure data consistency and integrity
* Automate transaction recording processes
* Improve inventory tracking accuracy
* Support reporting and operational efficiency

## Scope

The system manages the following business operations:

* Product management
* Customer management
* Order and invoice management
* Inventory management
* Sales transaction processing
* User access control and security

The system supports both:

* Offline sales at physical stores
* Online sales through e-commerce platforms

## Database Components

The database includes the following key components:

* Tables for managing products, customers, orders, invoices, and inventory
* Indexes to improve query performance
* Views for reporting and data analysis
* Functions for calculating totals and statistics
* Stored Procedures for handling transactions
* Triggers to enforce business rules
* User and Role management for system security

## Key Features

* Sales transaction recording
* Automatic inventory updates
* Customer information management
* Revenue and sales reporting
* Data validation and integrity constraints
* Access control and permission management

## Methodology

The following database design and management techniques were applied:
